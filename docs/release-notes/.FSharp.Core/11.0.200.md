### Added

### Fixed

* Fix struct tuples in query expressions and in lambdas converted to LINQ expression trees: selecting one no longer fails with "unreachable", and taking one apart no longer fails with a tuple index out of range. ([Issue #15522](https://github.com/dotnet/fsharp/issues/15522))
* Fix LINQ providers failing on queries composed over a tuple or record projection (for example the tuples of a nested query taken apart by the next `for`, or a record read by a later `Where`): tuple, struct tuple, record and anonymous record constructions now name the member each argument becomes, as C# anonymous types do. ([Issue #3782](https://github.com/dotnet/fsharp/issues/3782), [Issue #15133](https://github.com/dotnet/fsharp/issues/15133), [Issue #40](https://github.com/dotnet/fsharp/issues/40))
