### Fixed

* Fix struct tuples in query expressions and in lambdas converted to LINQ expression trees: selecting one no longer fails with "unreachable", and taking one apart no longer fails with a tuple index out of range. ([Issue #15522](https://github.com/dotnet/fsharp/issues/15522))
* Fix LINQ providers failing on F# functions in queries and in lambdas passed as `Expression<Func<..>>`: `fst`, `snd`, `isNull`, `box` and the math functions (`abs`, `sqrt`, `floor`, `ceil`, `round`, `truncate`, `sign`, `exp`, `log`, `log10`, the trigonometric functions, `min`, `max`, `**`) on primitive types now become the tuple reads, null comparisons, conversions and `System.Math` calls a C# lambda has, instead of calls into FSharp.Core.
